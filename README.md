# 虚拟书架

把 BookBuddy 导出的书目，按照家里书架的实际格局摆到一个虚拟书架上，方便查某本书放在哪个柜子、哪一层、从左数第几本。

- 只有一个网页文件（`index.html`），不需要安装任何东西
- 书目数据保存在你自己设备的浏览器里；开启多设备同步后，会另存一份到你自己的 GitHub 私有仓库，不经过任何第三方服务器
- Mac、iPhone、iPad 都能用，iPhone / iPad 可以添加到主屏幕当 app 用，没网也能打开

## 书架格局

```
        A          B        C
     [A7 柜顶]            [C7 柜顶]
     [A6]       [B6]      [C6]
     [A5]       [  ]      [C5]
     [A4]       [B5]      [C4]
     [A3]       [B4]      [C3]
     [A2]       [B3]      [C2]
     [A1]       [B2]      [C1]
                [B1]
```

- 层号从下往上数
- B 柜宽度大约是 A、C 的一半。B1–B4 是下面带木门的四个小格（从地面到 A4 的底板）；B5 是玻璃门后的高格，底板和 A4 齐平；B6 从 A5 一半的高度开始，柜顶和 A、C 齐平
- A7 / C7 表示柜顶上（放不进层里的大书）

格局写在 `index.html` 开头的 `LAYOUT` 里，书柜宽度、层数、每层的高度都可以改。

## 在 BookBuddy 里怎么填位置

`Physical Location` 填「书柜字母 + 层号」，比如 `A3`、`B1`、`C6`。只需要记到层，同一层里的书会自动排序（可以在设置里选按分类、书名、作者或加入时间排序）。

位置为空、或者书架上没有这个位置的书（比如填错成 `C55`），会放在书架下方的「未上架」区。

## 怎么用

1. 在 BookBuddy 里把书库导出成 CSV
2. 打开虚拟书架，点「导入 BookBuddy CSV」选这个文件（Mac 上也可以直接把文件拖进窗口）
3. 在搜索框里输入书名、作者、系列或 ISBN，简体繁体都能搜到。点结果会跳到那本书，书会在书架上闪几下
4. 点书脊可以看详情：作者、ISBN、出版社、备注、内容简介，以及在哪个柜、哪一层。BookBuddy 只记到层，所以层内的顺序是自动排的，不一定和实际摆放一样；在整理模式里按实际顺序拖一遍之后，详情里会显示「从左往右第几本」
5. 点上方的分类可以只看某一类书

以后新增或者移动了书：在 BookBuddy 里改好，重新导出 CSV 再导入一次就行。

### 整理模式：在虚拟书架上拖书

点「整理」后可以拖动书脊（iPhone / iPad 上要先按住书脊一下，等它拿起来再拖；直接滑动是滚动画布）：

- **同一层里拖动**：只改变顺序，记在这台设备上，不用动 BookBuddy
- **拖到别的层**：书会带一条橙色条纹，并加进「待同步」清单，比如《XXX》A3 → C5。目标层如果是自动排序的，书会按排序规则落位，黄线会标出它落下的位置

BookBuddy 没有开放修改数据的接口，所以虚拟书架没法自动改 BookBuddy。请按「待同步」清单在 BookBuddy 里手动改 Physical Location（清单可以一键复制），改完重新导出 CSV 再导入（清单底部就有「导入新的 CSV」），对应的条目会自动消掉。

重新导入时：

- 在 BookBuddy 里改了书名，待同步和手动排序都会保留
- 在 BookBuddy 里改成了另一个层，以 BookBuddy 为准，提示里会点名是哪本书
- 在 BookBuddy 里填了书架上没有的位置（比如打错字），待同步先保留，清单里会标出来

详情面板里的「移到」也能把书换到别的层，效果和拖动一样。

## 在 Mac 上打开

直接双击 `index.html`，用 Safari 或者其他浏览器打开就行。

## 在 iPhone / iPad 上打开（GitHub Pages）

iPhone / iPad 没法直接打开本地的 HTML 文件，需要把这个仓库发布成一个网页：

1. 用 GitHub Desktop 把这个仓库发布到 GitHub（Publish repository）
2. 在 GitHub 网页上打开仓库 → **Settings** → **Pages**
3. **Source** 选 `Deploy from a branch`，Branch 选 `main`、目录选 `/ (root)`，点 Save
4. 过一两分钟，页面上会显示网址，类似 `https://你的用户名.github.io/virtual-bookshelf/`

仓库里只有网页代码，没有你的书目（`.gitignore` 已经排除了所有 `.csv` 文件），所以仓库设成公开也没关系。免费账号只有公开仓库能用 GitHub Pages。

然后在 iPhone / iPad 上：

1. 用 Safari 打开上面的网址
2. 点分享按钮 → **添加到主屏幕**
3. 从主屏幕打开「书架」，点「导入 BookBuddy CSV」，从「文件」里选 CSV

建议一定要添加到主屏幕再用：Safari 会清理 7 天没打开过的网站数据，主屏幕上的 app 不受这个限制。另外主屏幕 app 和 Safari 的数据是分开的，要在主屏幕 app 里导入。

## 多设备自动同步

开启后，在 Mac 上导入 CSV、调整顺序、移动书，iPhone / iPad 打开时会自动拿到最新的结果，反过来也一样。数据存在你自己的 GitHub 私有仓库里（每次同步是一次提交，所以仓库的历史记录也是一份备份）。

### 第一次设置（只需要做一次）

1. 在 GitHub 上新建一个仓库，比如叫 `bookshelf-data`，选 **Private**，勾上「Add a README file」
2. 打开新建令牌的页面：<https://github.com/settings/personal-access-tokens/new>
   （也就是点 GitHub 右上角的**头像** → **Settings** → 左侧栏最底下的 **Developer settings** → **Personal access tokens → Fine-grained tokens → Generate new token**。注意是账号的 Settings，不是仓库里的 Settings）
   - **Repository access** 选 **Only select repositories**，只选 `bookshelf-data`
   - **Permissions** 里找到 **Contents**，设成 **Read and write**（新版页面可能要先点 **Add permissions**；其它都不用开）
   - 有效期可以设长一点；过期以后虚拟书架会提示，重新生成一个填进去就行
3. 马上复制生成的令牌（`github_pat_` 开头，离开页面就看不到了）
4. 在 Mac 上打开虚拟书架 → `⋯` → **设置同步…**，填入 `你的用户名/bookshelf-data` 和令牌，点「连接」

### 其它设备

在已经设置好的设备上点 `⋯` → **复制同步码**，到另一台设备上打开虚拟书架 → `⋯` → **设置同步…**（还没有书目的话，首页就有「从其他设备同步」），粘贴进去点「连接」。同一个 Apple ID 的 Mac 和 iPhone 之间可以直接用通用剪贴板粘贴。

iPhone / iPad 上 Safari 和主屏幕 app 的数据是分开的，要在主屏幕 app 里设置同步。

### 怎么同步、改冲突了怎么办

- 改动后几秒钟自动上传；打开页面、切回页面、联网时，以及每隔一分钟，会检查其它设备有没有改过
- 没网时照常用，联网后自动补传
- 两台设备都改过的话会逐条合并：每本书的移动、每一层的排序取较新的那次修改，撤销也算修改；书目跟着较新的那次 CSV 导入
- 在开着同步的设备上「从备份恢复」，会把备份里的状态同步到所有设备

### 安全

- 令牌只保存在你填写的那台设备上，不会进备份文件，也不会上传到仓库
- 令牌只能访问 `bookshelf-data` 这一个仓库；同步码里包含令牌，不要发给别人
- 不想用了：在每台设备上点「停止同步」，再到 GitHub 上删除这个令牌

## 换设备、备份

没开同步的话，书目、同层里的手动排序、待同步清单都只保存在当前设备上，各台设备互不相通。

要把一台设备上的整理结果搬到另一台设备：在 设置（右上角 `⋯`）里点「导出备份」（iPhone / iPad 上会弹出分享面板，可以存到「文件」或者隔空投送），得到一个 `.json` 文件，到另一台设备上用「从备份恢复」选这个文件即可。如果只需要书目，在另一台设备上直接导入 CSV 也行。
