    使用说明

    • 位置怎么写：书柜字母加层号，层号从下往上数，比如 A3、B5、C6。A7、C7 是柜顶上。
    • 更新书目：在 BookBuddy 里改好后重新导出 CSV 再导入。手动排序和待同步清单都会保留。
    • 找书：可以搜书名、作者、系列或 ISBN，简体繁体都能搜到。点搜索结果会跳到那本书。点上方的分类可以只看某一类。
    • 层内顺序：BookBuddy 只记到层，所以同一层里的顺序是自动排的，不一定和实际摆放一样。想让它一致，可以在整理模式里按实际顺序拖一遍。
    • 缩放：双指捏合，或者用右下角的按钮。Mac 触控板也能捏合，或者按住 ⌘ 滚动。
    • 整理：点「整理」后可以拖动书脊（手机和 iPad 上要先按住书脊一下再拖）。同一层里换顺序只记在本机；拖到别的层会加进「待同步」清单。
    • 未上架：位置为空、或者书架上没有这个位置的书，放在书架下方的「未上架」区。
    • 多设备同步：开启后，在一台设备上导入、整理、移动的结果，会自动出现在其它设备上。数据存在你自己的 GitHub 私有仓库里。
    • iPhone / iPad：建议在 Safari 里点分享 →「添加到主屏幕」，以后从主屏幕打开。Safari 里的网站数据 7 天不打开可能会被清掉，主屏幕上的不会；两边的数据也不互通。

    设置多设备同步

    书目、层内排序和待同步清单会保存在你自己的 GitHub 私有仓库里，每台设备打开时自动同步。

    已经在别的设备上设置过：在那台设备上点「⋯ → 复制同步码」，粘贴到下面任意一个框里。

    第一次设置的步骤
    1. 在 GitHub 上新建一个仓库，比如叫 bookshelf-data，选 Private，并勾上「Add a README file」。
    2. 打开新建令牌的页面（也就是点 GitHub 右上角的头像 → Settings → 左侧栏最底下的 Developer settings → Personal access tokens → Fine-grained tokens → Generate new token；注意不是仓库里的 Settings）。
    3. Repository access 选 Only select repositories，只选刚建的仓库；Permissions 里把 Contents 设成 Read and write。
    4. 生成后马上复制令牌（github_pat_ 开头，离开页面就看不到了），和仓库名一起填到下面。
    松开即可导入 CSV
